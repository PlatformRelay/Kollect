## Learnings

Class: sensor.

- A defensive check can make an existing mutant equivalent: after adding one, rerun the self-test
  before trusting it (G7: B1's shape check silenced G3 M17).
- A fix scoped to the reads a finding lists can leave the same defect on the read it did not list:
  apply the rule to every call of the kind (G7: the jobs read, R1-1).
