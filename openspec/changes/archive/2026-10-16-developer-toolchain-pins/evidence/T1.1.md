run() {

## Learnings

- sensor: a shrink-only list in bash needs a closed list of allowed mentions (definition + read
  forms), never a list of write forms; reviewers found four write forms in two rounds.
- sensor: self-test mutant values must not be a plausible next release (0.11.1 became a real bump
  hazard); use a value that never exists (99.0.0) or derive it from the tree.
- tooling: `grep -v | grep -q` under pipefail dropped a guard mode at random in
  ci_workflow_security_test.sh (15% on a 28 KB file); grep to /dev/null instead.
- sensor: a probe that matches lines already present proves nothing; tag inserted lines with a
  marker and probe every insertion.
