## Learnings

- tooling: the `@@` probe split hit again on `setup-task@@@`; any probe that starts with an action
  ref needs `[@]` (1.2's lesson, still manual).
- sensor: a hand-mutant `sed` must be line-addressed when the target text repeats in the file (the
  `empty-off` sed also mutated `check_tool`'s empty branch).
- guidance: when two clauses compare the same value (DTP-1 and DEV-MISE-01 on mise's task), give
  the value to one clause and keep presence in the other, so each mutant reds once.
