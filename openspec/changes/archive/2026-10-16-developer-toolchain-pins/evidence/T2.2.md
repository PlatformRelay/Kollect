## Learnings

- sensor: a "reads the variable" check must also forbid a task-level override of that variable:
  Task's task vars beat global vars, so the reference holds while another value runs.
- sensor: when a guard checks that a bot can see a pin, match the bot's regex exactly (one space,
  no trailing blanks); a looser match is green on lines the bot ignores.
- guidance: a "the run moved elsewhere" mutant (rather than "deleted") is what proves a block
  reader ends where the block ends.
