## Implementation notes (verified 2026-10-19 unless marked)

- Runner order as 2.7: argument check, `GREMLINS_` refusal (`compgen -e`, so an exported empty
  value counts), `MUTATION_FORCE_FAILURE` (`true` fails, empty or `false` continues, anything else
  fails with its own message), then `export GOFLAGS=-count=1` (G1 finding F1), `mktemp -d`,
  `reports=<dir>` to `$GITHUB_OUTPUT`, the fixture call and control check, three package calls,
  the formatter. The fixture call runs `.` in the fixture directory; the package calls run
  `./internal/<pkg>` in the repository root.
- Formatter package names are `internal/aggregate`, `internal/redact`, `internal/pathvalidate`;
  M6 resolves each `file_name` against `<repo root>/<package>/`. A `file_name` with a `/` fails.
- Workflow: no `concurrency:` (top-level keys are pinned to `name`, `on`, `permissions`, `jobs`,
  which also forbids `env:` and `defaults:`); `timeout-minutes: 15`; the upload step also sets
  `name: mutation-reports`, which W1 pins.
- The guard lists files with `git ls-files --cached --others --exclude-standard`: tracked plus
  untracked-not-ignored, so a local `.gremlins` git does not yet track still reds (gremlins would
  read it). Stricter than "tracked"; T2's mutants add each file to the copy's index anyway.
- R2 is stricter than its text: the failing fake call writes its report before exiting 1 (as a
  gated gremlins does), so only the exit status can tell the runner it failed, and the case asserts
  `gremlins failed on ./internal/redact`. That is what kills the `|| true` mutant in R2 (without
  it, the missing report would mask the defect as "no report").
- A forced run writes nothing to `$GITHUB_OUTPUT` (it fails before the directory exists), so the
  upload step gets an empty `path:` and fails too (believed from upload-artifact's required input);
  the run is red either way.
- Test change on change 7's guard: `ci_failure_report_test.sh` exact list, comment and message
  (`:1549-1557`) and a self-test mutant `MUT-1 list loses Mutation testing` next to `:426-427`.
