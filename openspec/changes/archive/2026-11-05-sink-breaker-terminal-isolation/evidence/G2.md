## Learnings

Class: sensor.

- A ten-run race loop is probabilistic; pair it with a deterministic `-count=3 -run` over only the failing-backend
  tests (no success in between) so mutants of the isolation are killed by exit status.
- The 2.1 race command has a second, unrelated flake (debounce-metric delta, ~1/10); "ten green runs" clauses on
  that command should name the failure mechanism they target.
