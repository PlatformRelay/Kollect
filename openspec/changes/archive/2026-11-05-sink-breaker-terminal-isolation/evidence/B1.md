## Learnings

- tooling: `exportRemoteInWorkdir` can be driven offline on a local bare repository (`file://`, go-git's file transport) by calling it directly; only `ExportFilesWithBranch`'s `isFileRemote` routing sends `file://` to the CLI engine. A go-git engine test does not need the integration build's HTTP server unless it must pass through `RunExportEnvelope`.
- guidance: a test-strengthening task has no base red; record the mutation table as its proof and add one mutant per routed call (here `foreignClaimError`'s body and its two `checkSingleClaims` call sites are separate mutants with separate rows).
