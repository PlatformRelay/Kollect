## Learnings

Class: sensor.

- A list-driven rewrite of an ordered reader keeps the read set but can change error precedence;
  an existing parity test (`TestCAParity_caRulesPrecedeCredentialLookup`) was the only sensor, and
  only the full suite ran it.
- Ginkgo suites refuse `go test -count>1` and `-ginkgo.repeat` is CLI-only: repeat the race run by
  invoking `go test -race -count=1 -run '^TestControllers$'` N times.
- `internal/sink/git` mirror tests fail under a group-writable umask: run the full suite with
  `umask 022`.
- A manager that is never started needs no API server when given a static REST mapper
  (`MapperProvider`), which lets a plain unit test call `SetupWithManager`.
