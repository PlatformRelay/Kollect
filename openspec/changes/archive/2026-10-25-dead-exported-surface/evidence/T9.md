## Learnings

- tooling: govet `shadow` does not flag a same-name binding whose outer variable is never used after the shadowing declaration — a multi-name package-var shadow (`ctx, cancel := …` vs `var (ctx, cancel …)`) can be half-flagged: `ctx` reported, `cancel` not. When fixing one name of a paired declaration, probe both and record the unflagged twin's disposition (verified 2026-10-07, register findings 4–5).
- guidance (propose to owner, already filed in evidence/T8.md): package-scoped golangci-lint in the per-task tier would have surfaced both findings at T1/T6 instead of the final gate.
- guidance (record for the loop, register finding 2): when a task resolves an earlier task's decision request, add a one-line resolution pointer to the earlier evidence file and keep its verdict untouched — the living row is tasks.md, evidence files are point-in-time.
- tooling: fresh-vs-cached suite evidence: a real post-edit run prints the tool's own seconds (51.779s/30.420s here); Go's cache prints "(cached)" or sub-second lines — cite the duration lines when claiming a fresh run.
