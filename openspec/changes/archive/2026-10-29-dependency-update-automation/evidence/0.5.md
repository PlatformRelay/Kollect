### The argv that works (contract for T16 and 2.3)

Run from the repository root `$root`, with `$image` the `renovate-image` value read from
`renovate.yaml`:

```bash
docker run --rm --network none -v "$root:/repo:ro" -w /repo \
  --entrypoint renovate-config-validator "$image" --strict --no-global renovate.json
docker run --rm --network none -v "$root:/repo:ro" -w /repo \
  --entrypoint renovate-config-validator "$image" --strict .github/renovate-config.json
```

- Mount: the root read-only at `/repo`; workdir `/repo`, so the file arguments are the
  repository-relative paths (no mount prefix). Run F shows `/repo/renovate.json` without `-w`
  works too.
- Entrypoint: `--entrypoint renovate-config-validator`, so the command does not depend on the
  image's entrypoint script.
- `--network none` works and is the least privilege; the pull happens before it, outside the
  container.
- The files must be readable by uid 12021 (world-readable, as a CI checkout is) or the call needs
  `--user "$(id -u):$(id -g)"`; an unreadable file fails closed (exit 1), never passes.
- Failure: any non-zero exit (1 for findings, 99 for a CLI error).

`probe-05.sh` (command line: `bash /tmp/dua-G0/scripts/probe-05.sh <repo-root>`):

```bash
#!/usr/bin/env bash
# 0.5 probe: run renovate-config-validator from the pinned image on today's files.
set -u
IMG='ghcr.io/renovatebot/renovate:44.179.1@sha256:f30ad41a40ab226734469eb61517d527a198a48b173cf6e0c3ee180927479293'
REPO=${1:?repo root}
run() {
  local label=$1; shift
  local t0 t1 rc
  t0=$(date +%s.%N)
  "$@" >"/tmp/dua-G0/out-$label.log" 2>&1
  rc=$?
  t1=$(date +%s.%N)
  printf '== %s  exit=%s  wall=%.1fs\n   argv: %s\n' "$label" "$rc" "$(echo "$t1 - $t0" | bc)" "$*"
  sed 's/^/   | /' "/tmp/dua-G0/out-$label.log" | tail -n 12
}
# A: entrypoint override, repo file, repo mode, no network
run A-repo-entrypoint-nonet docker run --rm --network none -v "$REPO:/repo:ro" -w /repo \
  --entrypoint renovate-config-validator "$IMG" --strict --no-global renovate.json
# B: global file, global mode, no network
run B-global-entrypoint-nonet docker run --rm --network none -v "$REPO:/repo:ro" -w /repo \
  --entrypoint renovate-config-validator "$IMG" --strict .github/renovate-config.json
# C: through the image entrypoint (no --entrypoint), no network
run C-repo-default-entrypoint docker run --rm --network none -v "$REPO:/repo:ro" -w /repo \
  "$IMG" renovate-config-validator --strict --no-global renovate.json
# D: repo file validated WITHOUT --no-global (global mode) to show the mode matters
run D-repo-as-global docker run --rm --network none -v "$REPO:/repo:ro" -w /repo \
  --entrypoint renovate-config-validator "$IMG" --strict renovate.json
# E: with network (default bridge) for wall-time comparison
run E-repo-network docker run --rm -v "$REPO:/repo:ro" -w /repo \
  --entrypoint renovate-config-validator "$IMG" --strict --no-global renovate.json
# F: absolute paths, no -w
run F-repo-abs docker run --rm --network none -v "$REPO:/repo:ro" \
  --entrypoint renovate-config-validator "$IMG" --strict --no-global /repo/renovate.json
```
