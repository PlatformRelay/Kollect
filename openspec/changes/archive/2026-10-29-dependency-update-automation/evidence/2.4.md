## Observations

- **`rebaseWhen` of a mixed branch** (reviewer B): Renovate builds a branch's config from its
  first upgrade after sorting (`workers/repository/updates/generate.js:217-229`, 44.179.1) and
  recomputes only `automerge` over all of them (`:250`). A group where a digest upgrade sorts
  first would carry the automerge rule's `rebaseWhen: behind-base-branch` while `automerge` stays
  false: it is rebased whenever it falls behind `main`, never merged. In these runs every mixed
  branch (`mon` `renovate/docker-images`, `renovate/go-toolchain`) resolved to `conflicted`.
  Cost only (extra CI runs); no requirement covers it. For stage B.

`helm-check.sh` (command line: `bash helm-check.sh /tmp/dua-G3/scratch-<copy> /tmp/dua-G3/logs/<copy>-branches.jsonl`):

```bash
#!/usr/bin/env bash
# 2.4 (b): every HELM_VERSION site of the scratch tree plus release.yaml's setup-helm input must be
# in renovate/helm (minor/patch) and in renovate/major-helm (major), and in no other branch.
# Usage: helm-check.sh <scratch-dir> <branches.jsonl>
set -euo pipefail
S=$1; B=$2
cd "$S"
# expected: every tracked file outside tests, docs and specs with a HELM_VERSION pin (v-prefixed
# version after :, =, :- or a quote), plus release.yaml's setup-helm input
exp=$( { git ls-files | grep -vE '^(hack/test/|docs/|openspec/)' | xargs grep -lE 'HELM_VERSION(:-|: "?|=)v[0-9]+\.[0-9]+\.[0-9]+' | sed 's|^|regex:|'; echo "github-actions:.github/workflows/release.yaml"; } | sort -u)
echo "expected sites:"; sed 's/^/  /' <<<"$exp"
rc=0
for br in renovate/helm renovate/major-helm; do
  got=$(/usr/bin/jq -r --arg b "$br" 'select(.branch==$b) | .upgrades[] | "\(.manager):\(.packageFile)"' "$B" | sort -u)
  if [[ "$got" == "$exp" ]]; then echo "ok - $br holds every Helm site"; else echo "FAIL - $br differs:"; diff <(echo "$exp") <(echo "$got") || true; rc=1; fi
done
other=$(/usr/bin/jq -r 'select(.branch!="renovate/helm" and .branch!="renovate/major-helm") | select(any(.upgrades[]; .packageName=="helm/helm" or .depName=="helm/helm" or .depName=="helm")) | .branch' "$B" 2>/dev/null | sort -u)
if [[ -n "$other" ]]; then echo "FAIL - helm upgrades in other branches: $other"; rc=1; else echo "ok - no helm upgrade outside the helm branches"; fi
# per site: the number of HELM_VERSION lines per file must equal that file's upgrades in each branch
for br in renovate/helm renovate/major-helm; do
  while read -r f; do
    want=$(grep -cE 'HELM_VERSION[^#]*v[0-9]+\.[0-9]+\.[0-9]+|HELM_VERSION=v[0-9]' "$f")
    have=$(/usr/bin/jq -r --arg b "$br" --arg f "$f" 'select(.branch==$b) | [.upgrades[] | select(.manager!="github-actions" and .packageFile==$f)] | length' "$B")
    if [[ "$want" == "$have" ]]; then echo "ok - $br: $f $have of $want sites"; else echo "FAIL - $br: $f $have of $want sites"; rc=1; fi
  done < <(sed -n 's/^regex://p' <<<"$exp")
done
exit $rc
```
