## Design decisions

- **7.1 scope.** `task lint:markdown` reported 31 issues in these 8 files (verified 2026-10-16): MD032 and
  MD038 as triaged, plus MD058 (blanks around tables, loop.md), MD012 (double blank, G4.md) and MD009
  (one trailing space, task-prompt.md). All five were fixed: MD058/MD012/MD009 are the same whitespace
  class and the gate is red until they go too. The dispatch exception (loop.md and task-prompt.md only
  for markdownlint, no content change) holds: `git diff -w --ignore-blank-lines a3880bc47~1 a3880bc47`
  shows one changed line, the MD038 one in G2.md, where `` `has version 2.14.0 ` `` became
  `` `"has version 2.14.0 "` `` (the trailing space is the point of the quote, so it is kept inside quotes).
  Fixes applied with `markdownlint-cli2 --fix` (repo config) on exactly those 8 files. No table row was
  touched; blank lines only went before/after whole lists and tables (verified by reading the diff).
  The markdownlint config ignores only `openspec/changes/**/reviews/**`; no other change's files were red.
- **7.2 reject, not resolve.** An `ARG` default is only a default: `docker build --build-arg B=…`
  replaces it, so a gate that resolved `FROM ${B}` from its default would certify a value the release
  build need not use. Rejecting is simpler (no ARG scoping rules: global vs stage ARGs, `${B:-x}`,
  `${B:+x}` forms) and fails closed. Final rule (after review round 2): any `$` in a FROM image fails with
  `FROM <word> names its image through a variable`, except a `golang:`-prefixed image, whose
  variable tag already fails the literal-version check. History: v1 cut the repository at the first
  `:` (bypass `localhost:5000/${B}:1.99.0`, astra round 1); v2 allowed `$` in the tag of a literal
  repository (bypass `localhost:${B}` with `B=5000/golang:1.99.0`, astra round 2: a "tag" value can
  hold `/` and `:`). So `debian:${DEB_TAG}`, a green control in v1/v2, is now a mutant; no Dockerfile
  in the tree uses a variable image (verified 2026-10-16, `git ls-files | grep -i dockerfile`).
  A variable *tag* on a literal repository is not a variable image: `golang:${V}` already fails the
  literal-version check; `debian:${DEB_TAG}` is not a Go image and passes (green control).
  `<variable>` entries are excluded from the "images disagree" set so a variable line fails once.
  The dispatch asked to cover `FROM ${B}`, `FROM $B`, `FROM ${B:-golang:1.27.2}`: one mutant each,
  plus `localhost:5000/${B}:1.99.0`, `localhost:${B}` and `debian:${DEB_TAG}`.
- **7.3 registry test via Describe.** `Register()` registers into controller-runtime's global
  `metrics.Registry`. It now delegates to `registerTo(prometheus.Registerer)` (no behaviour change)
  so the test can hand it a recording Registerer and leave the global untouched. A second test
  (review round 1) proves the delegation: after `Register()`, re-registering each checked collector
  in controller-runtime's `metrics.Registry` must return `AlreadyRegisteredError`; Gather is not
  used for the same reason as below. The labeled collector is skipped there: it is unchecked
  (no Desc), and client_golang accepts an unchecked collector twice. `TestRegister` and the new
  test share one `sync.Once`, since a second `Register()` in one process panics (that is also why
  `go test -count=2 ./internal/metrics/` panics on base `028bbc44c`; now it fails on
  `TestRegister`'s non-idempotent counter asserts instead, pre-existing and out of scope).
  Names come from each collector's `Describe`, not `Gather`: an unobserved `*Vec` has no children and
  gathers no family (believed, client_golang MetricVec semantics; the Describe path makes it moot).
  `customResourceLabeledCollector` builds descriptors per recorded series, so its Describe is empty
  on a fresh process; it is matched by type to `customResourceLabeledSeriesName`. The fqName is read
  from `Desc.String()` (`Desc{fqName: "…"`, client_golang v1.24.1 `desc.go:211`, read 2026-10-16);
  an unreadable Desc is a test error, not a skip.
- **7.4** `new_copy` sets a global `COPY` and is called directly, the pattern of
  `consistency_rbac_test.sh:282` and `consistency_metrics_test.sh`.
- **7.5** `reason.partition(":")` replaces two `split(":", 1)` index reads; a bare class token now
  falls through to the existing closed-class FAIL line.

## Learnings

Class: sensor.

- A "tag" built from a variable is not a tag: its value can hold `/` and `:` and name another
  repository; fail on any `$` in an image reference instead of parsing around it (G7).
- Test a delegating entry point through the real sink it delegates to (`Register()` →
  controller-runtime registry via AlreadyRegisteredError), not only the helper it calls (G7).
- `Register()` panics on a second call in one process: tests that call it share one `sync.Once` (G7).
- zsh is the Bash tool's shell here: `${PIPESTATUS[0]}` is empty; use `$pipestatus` or no pipe (G7).
