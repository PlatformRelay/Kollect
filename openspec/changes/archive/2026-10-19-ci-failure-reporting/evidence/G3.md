## Interface (fixed here; G4's workflow calls it)

```text
hack/ci/ci-failure-report.sh        # no arguments
  GITHUB_EVENT_PATH   workflow_run payload (read with jq; never interpolated)
  GITHUB_REPOSITORY   owner/repo; exported as GH_REPO for every gh call
  GH_TOKEN            read by gh only
```

Exit 0: done or nothing to do (not a scheduled run of this repository, no completed scheduled run,
no-op conclusion, no write needed). Exit 1: a `gh` call failed (its error on stderr, no further
call), a malformed id or input, an unknown conclusion, a full lookup page, or the logs were
unavailable (written anyway). The workflow (G4) passes the token as `GH_TOKEN` in `env:`.

Decisions taken here, each from spec.md or T1.1:

- `gh` calls, in order: `run list --workflow <path> --event schedule --status completed --limit 1
  --json databaseId,number,attempt,conclusion`; for a failure-class or cancelled run `run view <id>
  --attempt <n> --json jobs`; `issue list --author 'github-actions[bot]' --state all --limit 500
  --json number,state,author,labels,body`; for the chosen issue `issue view <n> --json comments`;
  then at most `run view <id> --attempt <n> --log-failed` and the writes. A success or no-op run
  never reads jobs (its conclusion decides).
- Unknown conclusion (none of the table's) → exit 1, no write (fail visible; **believed** to be
  unreachable for a completed run).
- Bot issue = `author.login == app/github-actions` and `is_bot`, label `ci-failure`, first body line a
  valid marker for this workflow path. Bot comment = `author.login == github-actions` (T1.1 F2) with
  a valid first-line marker for this path. Recorded key and event = last bot comment's marker, else
  the issue body's.
- Lookup limit 500; a page of 500 is refused (it counts every `github-actions` issue, T1.1 F1).
- The recovery comment is built here (marker `event=recovery`, run URL, no run-supplied text).
- Issue title `CI failure: <workflow name>`, the name from the payload with control characters
  dropped and cut at 200; a single quoted argument.
