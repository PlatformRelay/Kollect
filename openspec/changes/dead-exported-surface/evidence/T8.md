## Learnings

- tooling: kollect's `task test`/`task coverage` do NOT need Docker — envtest assets are pre-downloaded at `bin/k8s/<version>` and `make -s echo-kubebuilder-assets` resolves offline; Docker absence blocks only `test-integration`/`e2e` (kind/testcontainers). Verified 2026-10-07; the task prompt's Docker premise was wrong. A Docker-less host is NOT a reason to record these gates `not-run`.
- tooling: govet `shadow` prints only the shadowed declaration's line number, no file — when that line looks blank in the reported file, hunt package-level `var (...)` blocks across the package (here `suite_test.go:39`). Negative probes (2026-10-07): a same-named struct field in another file and a same-named local in another function do NOT trip the check; a package-level var does.
- guidance (propose to owner): run a package-scoped `golangci-lint run ./internal/<pkg>/...` in the per-task tier when the task adds or rewrites test files — the single final-gate lint run accumulates debt from all tasks (T8 surfaced 2 findings from T1/T6).
- tooling: `task coverage` on a detached base worktree needs `bin/{controller-gen,setup-envtest,k8s}` symlinks (bin/ is gitignored); then it runs offline in ~9 min, giving a measured before/after for the coverage fitness row.
