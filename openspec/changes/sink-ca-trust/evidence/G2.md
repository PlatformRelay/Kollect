## Learnings

- tooling: net/http does not follow a 307 for an AWS SDK PutObject (the body cannot be replayed),
  so a `CheckRedirect` guard is only exercised by a body-less request such as HeadBucket.
- tooling: a mutant that leaves an import unused fails the build, which is no kill; use a
  replacement that keeps every import (again, after G1's dead-code case).
- guidance: unit-tier "no request" claims cannot use a loopback counter (netguard refuses
  loopback); put the counter in the integration tier and assert it before the error.
