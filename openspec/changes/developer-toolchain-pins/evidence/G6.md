## Learnings

- tooling: a guard self-test can run on a throwaway snapshot (tracked files + `git init` + `git add
  -A -f`), so editing continues while it runs; the nested bump control relies on the same trick.
- tooling: the mise `jq` shim refuses a copy holding `mise.toml`, so CFC-2 run with such a copy as
  cwd fails every `go mod download` (PATH a dir with `/usr/bin/jq` first). Already a G1 lesson for
  gitleaks; it bites `jq` the same way.
- sensor: a go version check of `^v[0-9]` lets a query (`v1`) through; check full semver.
- guidance: a "move this step" mutant must move only its own step; deleting the job also removes
  every sibling step and another clause fires first.
