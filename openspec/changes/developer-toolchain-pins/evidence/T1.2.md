## Learnings

- sensor: a ported test suite inherits its blind spots; run hand mutants on the ported code, not
  only the ported cases (`section-off` survived all 12 old cases).
- tooling: a probe language that splits on `@@` breaks on a literal `@` before it; write `[@]`.
- guidance: a comment that names the check enforcing a rule must match that check's scope (CWS-6
  only sees guards CI already runs; review caught "every guard").
