### F1 — warm test cache: every covered mutant TIMED OUT (finding)

Runner argv **without** `GOFLAGS=-count=1`, run straight after the default-set run (test cache
warm), `probe-counts.sh`: aggregate TIMED OUT 5, redact TIMED OUT 13 and NOT COVERED 1,
pathvalidate TIMED OUT 12; 0 killed, 0 lived, exit 0 each. Rerunning the default set then gave
the same (pathvalidate TIMED OUT 7), and `--workers 1` gave KILLED 6, TIMED OUT 1.

Cause (read 2026-10-19, `internal/engine/executor.go:83-101` and `internal/coverage/coverage.go:97-114`
in the v0.6.0 module): the per-mutant timeout is the coverage run's elapsed time times the
coefficient (default 3). A cached `go test -cover` returns in about 50 ms, so the timeout is about
150 ms, shorter than a mutant's build. The recorded report is
`hack/test/testdata/mutation/reports/warm-cache-pathvalidate.json`.

The fixture is not affected (warm runs: control LIVED, twice), so the MUT-3 control does not catch
this: a warm-cache night would be green with every real mutant TIMED OUT, a measurement that
measures nothing. The nightly can hit it (believed): `.github/actions/go-cache` restores and, on a
key miss, saves `~/.cache/go-build`, which holds test results.

Not a contradiction of proposal.md or spec.md (both are silent on the test cache; the baseline
holds on a cold cache), so the probe does not stop. Handling for G2, inside the spec: the runner
exports `GOFLAGS=-count=1` before its first gremlins call (argv unchanged, R1's exact argv still
holds; an inherited `GOFLAGS` such as `-tags=x` is replaced, which also closes a narrowing source
the `GREMLINS_` refusal cannot see); R1 asserts each call saw it and a 2.8 mutant drops it. Even
with it, one of nine package runs had one TIMED OUT (aggregate run 1): report-only noise, recorded.

```bash
#!/usr/bin/env bash
set -uo pipefail
REPO="$1"
OUT="$2"
G=/tmp/mutprobe/gremlins-v0.6.0/gremlins
mkdir -p "${OUT}/default" "${OUT}/runner"
echo '{}' >"${OUT}/empty.yaml"
FLAGS=(--arithmetic-base --conditionals-boundary --conditionals-negation --invert-assignments
  --invert-bitwise --invert-bwassign --increment-decrement --invert-logical --invert-loopctrl
  --invert-negatives --remove-self-assignments)
cd "${REPO}" || exit 2
for pkg in aggregate redact pathvalidate; do
  s=$(date +%s.%N)
  "${G}" unleash --output="${OUT}/default/${pkg}.json" "./internal/${pkg}" >"${OUT}/default/${pkg}.log" 2>&1
  rc=$?
  e=$(date +%s.%N)
  printf 'default %s exit=%s secs=%.1f\n' "${pkg}" "${rc}" "$(echo "${e} - ${s}" | bc)"
  s=$(date +%s.%N)
  "${G}" unleash "--config=${OUT}/empty.yaml" "--output=${OUT}/runner/${pkg}.json" "${FLAGS[@]}" "./internal/${pkg}" >"${OUT}/runner/${pkg}.log" 2>&1
  rc=$?
  e=$(date +%s.%N)
  printf 'runner  %s exit=%s secs=%.1f\n' "${pkg}" "${rc}" "$(echo "${e} - ${s}" | bc)"
done
for mode in default runner; do
  for pkg in aggregate redact pathvalidate; do
    printf '%s %s: ' "${mode}" "${pkg}"
    jq -r '[.files[].mutations[].status] | group_by(.) | map("\(.[0])=\(length)") | join(" ")' "${OUT}/${mode}/${pkg}.json"
  done
done
```
