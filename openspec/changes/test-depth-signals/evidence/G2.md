### Envtest provisioning

`make setup-envtest` (5.2 s, exit 0), then `make -s echo-kubebuilder-assets` printed
`<repo>/bin/k8s/1.36.2-linux-amd64`. `make setup-envtest` prints that path to stderr **without a
trailing newline**, so a later `echo` lands on the same line (`...linux-amd64seed 2` in the probe
log): the script must keep setup's output off the line that carries the seed.

### Probe script (run outside the repository as `bash split.sh 2` from the repo root)

```bash
#!/usr/bin/env bash
set -euo pipefail
seed="$1"
make setup-envtest >&2
KUBEBUILDER_ASSETS="$(make -s echo-kubebuilder-assets)"
export KUBEBUILDER_ASSETS
[[ -n "${KUBEBUILDER_ASSETS}" ]]
echo "seed ${seed}"
mapfile -t all < <(go list ./... | grep -v /e2e)
mapfile -t gk < <(go list -f '{{.ImportPath}} {{.Dir}}' ./... | while read -r p d; do
  if grep -l 'RunSpecs' "${d}"/*_test.go >/dev/null 2>&1; then echo "${p}"; fi; done)
plain=()
for p in "${all[@]}"; do [[ " ${gk[*]} " == *" ${p} "* ]] || plain+=("${p}"); done
echo "ginkgo: ${gk[*]}"; echo "plain: ${#plain[@]} packages"
rc=0
s=$SECONDS
go test -shuffle="${seed}" -count=3 "${plain[@]}" || rc=1
echo "plain wall: $((SECONDS - s))s"
for i in 1 2 3; do
  s=$SECONDS
  go test -shuffle="${seed}" -count=1 "${gk[@]}" || rc=1
  echo "ginkgo run ${i} wall: $((SECONDS - s))s"
done
exit "${rc}"
```
