## Learnings

- tooling: bumping go.mod's Go can break pinned analysis tools whose embedded golang.org/x/tools predates that Go (golangci-lint v2.13.1: export data v5; govulncheck v1.1.4: intermittent SSA panic). CFC-2 as specified only compares a tool's `go` directive against go.mod, which is the other direction. Proposed for task 2.1: run each pinned analysis tool once under go.mod's Go (see Decision request).
- tooling: this host's umask 002 reds two `internal/sink/git` tests (dir 0775). Run `task test` with `umask 022`, or the tests should set the mode explicitly. Proposed for RECURRING-DEFECTS.
- tooling: the mise shims for gitleaks and jq fail in some directories (no version set, untrusted mise.toml). Use `~/.local/share/mise/installs/gitleaks/8.30.1/gitleaks`, and give scratch copies no mise.toml.
- guidance: Renovate's group precedence is last-match-wins. The robust guard is "the group rule is the last rule that sets a groupName", not "after the named rules". The round-1 version was bypassable three ways.
- sensor: a local `renovate --platform=local` with `RENOVATE_DRY_RUN=lookup`, on a `git archive` copy, makes grouping claims verifiable in about a minute.
