## Design decisions

- **Literal scan through a Go-aware masker**: comments are dropped and string literals ("…", raw) collected, so a
  name in a comment is not registered (spec: "string literals"). Rune literals are skipped.
- **Histogram = registered under `HistogramOpts`** (its `Name` a literal or a const resolving to one). Only those take
  `_bucket|_sum|_count`. A `HistogramOpts` whose Name does not resolve fails.
- **Docs completeness is by exact name**: a histogram mentioned only as `_bucket` is not documented.
- **Blind spots fail closed**: `Namespace:`/`Subsystem:` in `internal/metrics`, and a non-test `.go` file under
  `api cmd internal pkg test` (outside `internal/metrics`, `testdata`, `vendor`) importing the Prometheus client.
  These go one step past the spec text; they exist so the spec's "registered set" cannot silently miss a metric.
- **Empty scans fail**: source set, docs names, rule names; a missing docs page or rules template fails by name.
- **Mirror is an exact set match** (missing and extra both fail).
- Python inside bash like the other consistency guards; plain `python3`, stdlib only. `task check` picks it up by
  glob; `ci.yaml` untouched (6.1).

## Learnings

- class: sensor. A name scanner must read whole tokens of the target grammar (Prometheus: `[A-Za-z0-9_:]`), or a typo with a
  registered prefix passes (round 1).
- class: sensor. When a parser keeps only the forms it recognises, make it fail on any leftover, or valid input it does not
  model is silently dropped (round 2: const entry in the mirror list).
- class: sensor. Match import paths against parsed string-literal values, not one quote style (round 2).
- class: tooling. A gate-mutant runner must exit non-zero on a survivor or a not-landed mutant; retarget its mutants when a
  fix rewrites the line they patch (one went not-landed in FINAL and the runner caught it).
- class: tooling. The commit-message hook matches the whole Bash command string: keep model names in evidence edits out of
  any command that also runs `git commit`.
