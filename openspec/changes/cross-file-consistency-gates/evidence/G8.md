## Design decisions

- **8.1** The `img !~ /^golang:/` exemption is gone: any `$` in a FROM image prints `<variable>` and fails
  with `FROM <word> names its image through a variable`. The version parse strips `@…` and `-…`, so a
  variable there was invisible to the literal-version check (C1, verified by the red below).
  Consequence: the existing `golang:${GO_VERSION}` mutant now reds on the variable rule, so its sentinel
  changed from `is not a literal Go version` to `names its image through a variable` (self-test change,
  same mutant, stricter rule).
- **8.2 Docker's rule, not a guess.** BuildKit (docker buildx v0.38.0, `docker buildx build --check` on
  `scratch`, `G8-docker-probe.sh`, verified 2026-10-16) reads all three spellings as one FROM:
  - comment line inside a `FROM \` continuation: skipped, stage `builder` defined, no warning;
  - blank line inside the continuation: skipped, stage defined, warning `NoEmptyContinuation`
    (`--check` exits 1 on the warning; a build only warns);
  - a comment ending in `\`: only a comment, the next line's `FROM` is read.

  The awk parser now matches: inside a continuation, comment and blank lines are skipped; outside one,
  a comment line is dropped before the continuation test, so it never continues. The third spelling
  was not in the finding; it is the same parser hole (a comment swallowed the next FROM, verified
  exit 0 before the fix) and costs one mutant.

### G8-probe.sh

- Run as (from the repository root, with the file at `evidence/G8-probe.sh`): `bash evidence/G8-probe.sh <repo>`
- Input revision: `d4b943806` (before the 8.2 fix: exit 0 on all three) and `4409d94dc` (after: exit 1); script as committed in `5d01c4a0e`

```bash
#!/usr/bin/env bash
# G8 probe: run the CFC-1 gate on a scratch copy whose Dockerfile builder FROM is replaced by
# one of three spellings (comment line / blank line inside a continuation, comment ending in a
# backslash). Prints the gate's exit code per case. Usage: G8-probe.sh <repo-root>
set -uo pipefail
ROOT="${1:?repo root}"
GATE="${ROOT}/hack/test/consistency_go_toolchain_test.sh"
TMP="$(mktemp -d)"
trap 'rm -rf "${TMP:?}"' EXIT

probe() {
  local label="$1" repl="$2" d="${TMP}/${3}"
  mkdir -p "${d}/.github"
  cp "${ROOT}/go.mod" "${ROOT}/renovate.json" "${ROOT}"/Dockerfile* "${d}/"
  cp -R "${ROOT}/.devcontainer" "${d}/"
  cp -R "${ROOT}/.github/workflows" "${ROOT}/.github/actions" "${d}/.github/"
  sed -i -E "s/^FROM golang:[^ ]+ AS builder/${repl}/" "${d}/Dockerfile"
  local out rc
  out="$(bash "${GATE}" "${d}" 2>&1)" && rc=0 || rc=$?
  echo "${label}: exit ${rc}: $(grep -m1 -E 'FAIL: Dockerfile:|^ok' <<<"${out}")"
}

probe "comment line in continuation" 'FROM \\\n# pinned below\n  golang:1.99.0 AS builder' a
probe "blank line in continuation" 'FROM \\\n\n  golang:1.91.0 AS builder' b
probe "comment ending in backslash" '# builder stage \\\nFROM golang:1.90.0 AS builder' c
```

### G8-docker-probe.sh

- Run as (from the repository root, with the file at `evidence/G8-docker-probe.sh`): `bash evidence/G8-docker-probe.sh` (docker buildx v0.38.0)
- Input revision: none from the repository (the Dockerfiles are written by the script); run 2026-10-16 at `4409d94dc`; script as committed in `5d01c4a0e`

```bash
#!/usr/bin/env bash
# G8 probe: how BuildKit's own parser reads the three spellings. `docker buildx build --check`
# parses and lints the Dockerfile; `scratch` needs no pull. A stage named by the image line
# proves the FROM took the image after the comment/blank line.
set -uo pipefail
TMP="$(mktemp -d)"
trap 'rm -rf "${TMP:?}"' EXIT

run() {
  local label="$1" body="$2" d="${TMP}/${3}"
  mkdir -p "${d}"
  printf '%b' "${body}" >"${d}/Dockerfile"
  echo "== ${label}"
  docker buildx build --check "${d}" 2>&1 | grep -vE '^#[0-9]+ (DONE|\[internal\]|transferring)' | tail -12
  echo "exit ${PIPESTATUS[0]}"
}

run "comment line in continuation" 'FROM \\\n# pinned below\n  scratch AS builder\nFROM scratch\nCOPY --from=builder / /\n' a
run "blank line in continuation" 'FROM \\\n\n  scratch AS builder\nFROM scratch\nCOPY --from=builder / /\n' b
run "comment ending in backslash" '# builder stage \\\nFROM scratch AS builder\nFROM scratch\nCOPY --from=builder / /\n' c
```
