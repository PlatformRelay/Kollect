  the two newest minors, stable only: `go1.27.2`, `go1.26.9`.

  listing, not hand-written: `curl -fsS 'https://go.dev/dl/?mode=json&include=all' | jq '[.[] |

## Learnings

- class `guidance`: a fail-closed numeric compare in bash needs bounded canonical numbers: `((a < b))`
  inside `if` turns an arithmetic error (leading-zero octal) into "false", and values past 2^63 wrap —
  both produce a false green. Validate digits (`(0|[1-9][0-9]{0,3})`) before any `(( ))`.
- class `guidance`: bound curl (`--max-time` × retries + `--retry-max-time`) inside the job's
  `timeout-minutes`, or the sensor's own failure message never prints.
- class `tooling`: in a runner, `grep -v … | grep -q` under `pipefail` can SIGPIPE and read as "no
  match" on larger files; use `grep … >/dev/null`.
- go.dev `?mode=json` lists only the two newest minors; `&include=all` (2.2 MB) is needed for any older minor.
