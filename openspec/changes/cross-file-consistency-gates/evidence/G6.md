- **G2, fixture deleted from the shared module cache (parallel-unsafe)** — handled for CI by ordering, not by a
  private GOMODCACHE. Steps of a GitHub job run one at a time; the lint job has no backgrounded command (verified:
  no `&` in any lint run body, 2026-10-15); other jobs run on separate runners with their own `~/go/pkg/mod`. A
  private GOMODCACHE would make the self-test re-download the repo's and every tool's modules on each run (G2's
  reviewer estimate: toolchain + dependency download) for a race that cannot happen in CI. A ci.yaml comment
  records why the step is safe. Residual: two local runs of the self-test in parallel on one machine (e.g. two
  worktrees) can still race → deferred to stage B / a guard follow-up (unique fixture module name per run would fix
  it at no cost).
- **Lint step timeouts** — tried `timeout-minutes` on the two network-bound tool-pins steps; `dist_ci_wiring_test.sh`
  (GATE-CIWIRING-02) rejects any lint step key outside its closed allowlist (`name run uses with env shell`).
  Widening that allowlist is not this task's call (task-prompt: never widen an allow-list), so the steps carry no
  timeout; the job default (360 min) applies. Proposal below.

### Proposal (not done): move the tool-pins self-test to its own job

A `tool-pins` job (checkout, go-cache, make; `bash hack/test/consistency_tool_pins_test.sh --self-test`) running in
parallel with `lint` would keep lint near 10 min and give the self-test its own runner (and modcache). Cost and owner
steps: CWS-6 requires every guard mode to be invoked from a REQUIRED job, so the new job must join
`hack/release/verify-eligibility.sh` `required_checks` and the `protect-main` ruleset (owner action), and it must stay
unconditional like `lint` (docs-only PRs too), which `ci_docs_gate_test.sh` would then have to cover. Optional
companion: allow a positive `timeout-minutes` in `dist_ci_wiring_test.sh`'s STEP_KEY_ALLOWLIST (with a
`timeout-minutes: 0` mutant), so network-bound lint steps can be bounded. Both are operator decisions.
