## Learnings

- class `sensor`: a wiring rule must take the required modes from the spec, not from the guard's own code, or deleting
  the mode deletes the requirement (round 2).
- class `sensor`: count occurrences, not lines, when a check means "exactly one call" (`grep -o | wc -l`, not `grep -c`).
- class `guidance`: a job timeout equal to its step's timeout lets checkout eat the step's budget; require job > step.
- class `tooling`: `dist_ci_wiring_test.sh` allows only `name run uses with env shell` on lint steps: no step
  `timeout-minutes` in lint without an owner decision.
