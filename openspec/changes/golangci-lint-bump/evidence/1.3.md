staticcheck 12. Class-for-class identical to probe.md §5.

**IMPORTANT (verified against the linter source, jgautheron/goconst v1.11.0 +
golangci-lint v2.13.1 adapter):** golangci-lint's `uniq-by-line` (default true) suppresses
goconst findings on lines that already carry one. A run with `--uniq-by-line=false` shows
**56 goconst issues**: the 44 visible ones plus 12 hidden ones — `profile` ×4 (value
matches existing const `StaticRefTypeProfile`), extra positions of `series` ×2, and whole
strings `result` (10 occ), `version` (8), `resource` (8), `profile` (8) whose
first-position-per-file always collides with an already-flagged string. Fixing only the
visible 44 would let the hidden 12 unhide. The fix set is therefore every string with ≥3
non-call occurrences per package (goconst excludes direct call arguments by default
`ExcludeTypes: [Call]`): collect `namespace`,`config`; controller `Exported`; metrics
`profile`(→ existing const),`gvk`,`series`,`controller`,`result`,`kind`,`sink_type`,
`group`,`version`,`resource`,`kollect_inventory_items_total`,
`kollect_collect_items_total`,`gauge`,`counter`,`histogram`; pipeline `string`; bigquery
`cluster`,`exported_at`; mongodb `inventory_namespace`,`inventory_name`,`target_name`,
`source_uid`; git `origin` (incl. call-arg sites for coherence); preview `team-a`,`api`.
