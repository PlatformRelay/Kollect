  as a read-only probe when there IS drift leaves a modified working tree (here: the CRD regen was
  reverted so the regeneration stays in T07's commit). T07/T09/T10 will run it for real; budget a
  revert or the regen commit when it is red.
- tooling: `KUBEBUILDER_ASSETS` must be an absolute path for `internal/controller`'s Ginkgo
  envtest suites — a relative path resolves against the package directory and BeforeSuite fails
  with `fork/exec bin/k8s/...: no such file or directory`, skipping all 53 specs.
- guidance: recording every gate run (command, sha, exit, result) in the evidence before writing
  the review brief kept round 1 free of missing-record findings — the register's only finding was
  about the evidence's sanction, not the sensors. Keep the order for T03+.
- spec: TSP-1's one-write scenario ("no second Status().Update site") is now pinned by
  `TestClusterTargetSetReady_persistsCountAndFilterInOneWrite` (updates==1 asserted); T07's
  implementation must route the count through `persistFilterStatusIfSkipped`, not add a write site.
