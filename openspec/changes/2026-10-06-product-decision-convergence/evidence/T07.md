## Learnings

- tooling: `hack/gen-glossary.py` needs PyYAML; the system python3 lacks it and the drift
  gate shells out to bare `python3` — run the gate with the mise python 3.12 bin on PATH
  (`pip install pyyaml` once).
- guidance: a unified register can headline BLOCK on a severity promotion while both
  legs' own verdicts are CONCERNS and one leg's disposition matches the implementer's
  pre-declared deferral — verify findings against the spec and map on the verified
  findings, recording the promotion, not on the headline verdict.
- spec: a "mirroring X" claim needs an equality assertion, not a re-typed copy of X's
  expectations — the copy keeps passing while the two sides drift apart.
- sensor: narrowing a pre-existing test's fixture (skipsWrite → seeded measured zero) can
  orphan incidental coverage the test carried before — after updating a premise, check
  which sibling coverage it held and pin it explicitly (here: the derived nil→0
  measured-zero write).
